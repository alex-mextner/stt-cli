# Pinned development dependencies — the ONLY Python packages this project has.
#
# stt-cli itself declares zero runtime dependencies on purpose (the engine is a native
# binary and every media operation shells out to ffmpeg), so there is nothing to pin for
# users. This file exists for two reasons:
#
#   1. The dependency-audit CI gate scans a pinned `requirements*.txt` as DATA. Given only a
#      `pyproject.toml` it cannot audit anything without building the project, so it fails
#      closed — correctly, but permanently. This gives it something real to check.
#   2. It pins the exact linter, type-checker and test-runner versions CI uses, so a tool
#      release cannot turn a green branch red overnight.
#
# Regenerate after changing the dev/test extras:
#   uv pip compile --extra dev --extra test -o requirements.txt pyproject.toml
#
